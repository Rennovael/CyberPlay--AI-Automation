# CyberPlay AI Automation

CyberPlay AI Automation adalah project automation berbasis shell scripting dan AI untuk membantu monitoring sistem, server, dan jaringan secara realtime.

## Features
- Monitoring CPU
- Monitoring Memory
- Network Checking
- Automation Logging
- AI-Based Analysis Concept
- Realtime Monitoring

---

## Technologies
- Bash Shell
- Linux
- GitHub Actions
- Docker

## Installation

Clone repository:

```bash
git clone https://github.com/username/CyberPlay-AI-Automation.git
```

Masuk ke folder project:

```bash
cd CyberPlay-AI-Automation
```

Berikan permission script:

```bash
chmod +x monitoring.sh
```

Jalankan program:

```bash
./monitoring.sh
```
